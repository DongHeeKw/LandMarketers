# 24. Owner actions & learning-first kick-off

## 역할
창업자는 지형 탐색이 이해하기 쉬운지, 농지/토지를 알아볼 때 어떤 질문을 가장 먼저 하고 싶은지 피드백한다. Agent는 좌표계·공간연산·법규 참조 버전 관리와 테스트 책임.

## 화면 및 행동 계약
LM-U01: 3D 지형 첫 화면(콘셉트에는 '시각화' 명시) → 지역 검색.
LM-U02: 경계 레이어 → 선택 필지/면적/지목/데이터 근거. 선택된 필지 ID가 2D·3D에서 동일.
LM-U03: 거래 정보 조회 → 월/지역별 공개 거래 추이, 숨긴 지번은 정확히 특정 필지와 결합하지 않음.
LM-U04: 용도지역/중첩 규제 레이어 → 충돌 시 인간 공식 검토 필요 표시.
LM-U05: 농업/시설/임대 시나리오 → '확인해야 하는 절차' 제공, 법적 허가 판정 아님.
LM-U06: 출처·적용 기준일·미확인 사항이 포함된 인쇄/공유용 리포트.
LM-U07: 법적 매매 중개/거래 수수료는 초기 범위에서 제외.

## 핵심 TDD
1. EPSG 좌표변환 테스트(정확도 허용범위와 원본 CRS 명시).
2. 폴리곤 홀/겹침/경계 포함의 공간교차 테스트.
3. 일부 지번 미공개 거래자료에 대한 정확한 필지 가격 잘못 연결하지 않음 테스트.
4. 규제 룰의 효력 발생·만료일 테스트.
5. 규칙 부재/모순은 UNKNOWN/REVIEW_REQUIRED 반환.
6. 지형 시각화가 2D 공식 사실을 변경하지 않음.

## 학습
기초 좌표·위도/경도 → Polygon → SQL/PostGIS의 ST_Intersects → 법규 engine → 3D terrain tile. 기능 PR마다 간단한 입력·출력 표와 시각적 비교 첨부.

## 확인 전 주장 금지
빈 땅=유휴토지, 토지 소유자의 매도 의사, 필지별 계약값, 건축 가능 확약, 개발 수익 보장.
