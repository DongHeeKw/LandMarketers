# 운영 및 저비용 배포

## 환경
- Vercel: 시각화 앱의 비상업적 초기 테스트와 Preview
- 개인 Ubuntu PC: 지적·규제·거래정보 ETL 및 사전 집계
- PostgreSQL/PostGIS: 실제 경계 및 관계 데이터 처리
- 공개 프론트: 가정용 PC가 일시 중단돼도 이미 검증된 정적 공간정보 스냅샷 열람 가능
- 홈서버 상시 운영 전 에너지·전력·장애 비용 실측

## 필수 보안·법적 제약
DB 비공개, 서버에만 API 인증키 저장, spatial bbox 제한, SQL 바인딩, 라이선스 검증. 실거래가 일부 지번 비공개는 정확한 개별 필지 거래값으로 연결 금지. 실제 중개·수수료·소유자 연락 연계는 법적 검토 완료 전 OFF.

## Domain/DNS
기본 `vercel.app` 주소로 MVP. 유료 서비스 출시 때 무료 Vercel 플랜 사용 조건 재검토. 독립 도메인 하나 구매 후 무료 Cloudflare DNS를 붙일 수 있으며, 등록·갱신료는 지속 발생. 도메인보다 SEO 품질/사용자 문제 해결이 우선.

## 캐시·장애
원본 출처별 마지막 성공 갱신, 데이터 효력 시점, API 장애 경고. CDN/정적 타일에서 차단되지 않는 공개 정보는 계속 보이도록 한다. 최신성 중요 쿼리는 결측·지연 상태를 명확히 표시한다.

## 검증
API 장애 30분 모의 테스트, 백업 복구, 캐시 만료, 수집 체크포인트 재시작, WebGL 비지원 2D fallback, 개인정보 최소 수집.
